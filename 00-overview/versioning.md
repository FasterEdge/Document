# 版本策略

## 当前基线

当前生态运行版本统一为：

```text
1.0.20260826
```

含义：

- `1.0`：当前公开接口和文档组织代际。
- `20260826`：发布日期，格式 `YYYYMMDD`。

## 适用范围

该基线用于：FasterEdge、四个平台 DontCrack、ProxyArea、SimpleWebShell、SimpleTimeService，以及 TsnHub 的 CMake 项目版本。

Example 和 `.github` 属于示例/组织元数据，不要求暴露运行版本。

## 兼容性

- 文档基线描述同一天验证过的生态快照，不表示所有组件共享同一个二进制或发布包。
- 同一代内，只修订文档或兼容实现时可更新日期部分。
- 破坏命令参数、HTTP 响应或组件生命周期语义时，应提升主/次版本。

## 历史版本

历史操作手册、软著材料或变更日志中的旧版本不得改写为当前版本。这些资料不属于本公开文档仓库。

## 发布检查

```bash
# 在 Document 内检查过时运行版本
rg '1\.1\.202|1\.0\.20260225|1\.0\.0' --glob '*.md'
```

允许命中历史变更日志，但当前状态、示例响应和启动横幅必须使用 `1.0.20260826`。
